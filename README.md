# ExamSphere – Online Examination System

ExamSphere is a web-based Online Examination System developed to conduct and manage online examinations efficiently.

The system provides separate modules for administrators and students. Administrators can manage students, subjects, categories, questions, exams, results and reports, while students can register, log in, attend available exams and view their examination history and results.

---

## 🚀 Features

### 👨‍💼 Admin Module

- Admin Login
- Admin Dashboard
- Student Management
- Subject Management
- Category Management
- Question Management
- Exam Management
- Result Management
- Reports and Analytics
- Admin Profile
- Admin Settings
- Admin Logout

### 👨‍🎓 Student Module

- Student Registration
- Student Login
- Student Dashboard
- Student Profile
- Available Exams
- Online Examination
- Exam History
- Result Viewing
- Student Logout
